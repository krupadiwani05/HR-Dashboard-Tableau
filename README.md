# HR Analysis Dashboard | Tableau

> Understanding employee attrition through data-driven insights.

An interactive Tableau dashboard designed to analyze workforce data, employee attrition, job satisfaction, and departmental trends.

## Dashboard Preview

![HR Analysis Dashboard](HR%20Analysis%20Dashboard.png)

## Dashboard Analysis

- **Attrition by Gender** — Compare employee attrition across genders.
- **Department-wise Attrition** — Explore employee turnover across departments.
- **Education Field** — Analyze attrition across educational backgrounds.
- **Age Group Analysis** — Explore workforce demographics.
- **Job Satisfaction** — Examine employee satisfaction ratings.
- **HR KPIs** — Track attrition rate, attrition count, and active employees.

## Tools & Techniques

**Tableau** · **Data Analysis** · **Data Visualization**

## Objective

Transform HR data into meaningful insights to understand employee turnover and support better HR decision-making.
